# City Information Office Request Form System

A complete, standalone responsive web application for the City Government of Bago's City Information Office Request Form System.

## Features

- 📱 **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- 🖨️ **Professional Print Layout**: Automatically generates a 2-up side-by-side printable form in landscape orientation
- ✅ **Form Validation**: Ensures all required fields are filled before printing
- 🎯 **Conditional Fields**: Smart form fields that appear based on service selection
- 🎨 **Modern UI**: Clean, professional interface matching government document standards

## Services Covered

- Graphic/Layout Design
- Photo Coverage
- Video Coverage
- Video Coverage with Interview
- Drone Coverage
- Radio Guesting
- Video Editing
- Social Media Posting
- Copy of Photo/Video Materials

## How to Use

1. Open the application in any modern web browser
2. Fill out all required fields
3. Select the services you need
4. Fill conditional fields if applicable (e.g., due dates, posting dates)
5. Click "Print Form / Generate Document" to create the official document
6. Print in landscape orientation for proper 2-up layout

## Technology Stack

- HTML5
- CSS3 (with Flexbox/Grid and Print Media Queries)
- Vanilla JavaScript
- No external dependencies required
