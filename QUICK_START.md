# 🚀 Quick Start Guide

## For Public Users (Requestors)

### How to Submit a Request
1. Go to: **https://cio-form.vercel.app**
2. Fill out all required fields (marked with *)
3. Select services needed
4. Read the note and check the acknowledgment box
5. Click "Submit Request"
6. **Save your Control Number!** (format: CIO-YYYYMMDD-XXXX)
7. Optionally print the form for your records

### What Happens Next?
- CIO team receives instant notification
- You will be contacted via phone or messenger
- Request will be reviewed within 3 working days

## For CIO Admin Staff

### Access Admin Dashboard
1. Go to: **https://cio-form.vercel.app/#admin**
2. Enter password: `CIOBago2026`
3. Click "Login"

### Manage Requests

#### View All Requests
- See complete list in table format
- Sorted by newest first
- All contact info and details visible

#### Contact Requestor
- **📞 Call**: Click to dial phone number
- **💬 Messenger**: Click to open Facebook Messenger

#### Update Status
Use dropdown to change status:
- Pending → Contacted → Approved/Declined → Completed

#### Reprint Form
- Click 🖨️ button to generate official 2-up form
- Print directly or save as PDF

#### Export Data
- Click "📥 Export to CSV" button
- Save backup of all requests
- Open in Excel/Google Sheets

### Quick Actions Cheat Sheet
